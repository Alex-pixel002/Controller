# DIY Hall-Effect PC Controller

A DIY wired PC game controller based on the open-source XWii Controller project.

## Features

- Hall-effect analog joysticks
- Hall-effect analog triggers
- Dual vibration/rumble motors
- D-pad
- A/B/X/Y buttons
- Shoulder buttons
- USB PC connection
- XInput compatibility
- 3D-printable controller housing

## Project Goal

I am building my own version of the XWii Controller for PC.

Planned modifications include:
- Xbox-style A/B/X/Y button arrangement
- Custom controller design
- Testing and documenting the finished controller

## Original Project
